# Боевой маршрут по доступным клеткам

Исправлено 2026-11-07.

## Что сделано

- Для манёвра строится путь по восьми соседним направлениям в пределах доступных клеток текущего конуса. Учитываются инерция, оставшиеся ОП, границы поля и помощь повороту у края.
- Каждый отрезок маршрута проверяется на пересечение занятой противником клетки, включая касание её угла. Если цепочка отсутствует, цель недоступна.
- При наведении отображается зелёная линия пути. После клика модель последовательно проходит соседние точки и плавно поворачивается по ходу движения. Принятый маршрут выделяется на время анимации.
- ИИ использует общий расчёт доступности. Анимация противника проходит по рассчитанным клеткам каждого манёвра его хода.
- Отмена воспроизводит принятую траекторию в обратном порядке. Она работает и после сохранения и загрузки боя.

Маршрут строится для текущего манёвра. Конус следующего манёвра рассчитывается из нового положения и курса. Стоимость ОП вычисляется как `ceil(distance(start, target))`, данные хода хранятся в существующей истории `combat.movement`.

Итоговый курс корабля определяется последним отрезком принятого пути. На конце линии показана стрелка прибытия. Модель, следующий конус и секторы оружия используют это направление. История каждого манёвра хранит `facing` — курс до перемещения. Подробности согласованного расширения приведены в `docs/COMBAT_FACING.md`.

Старые сохранения могут содержать манёвр, разрешённый прежней проверкой прямой линии, для которого отсутствует допустимая цепочка клеток. При отмене такого манёвра модель сразу возвращается на сохранённую клетку и получает соответствующий курс. Этот случай проверен отдельным сценарием совместимости.

## Файлы

Созданы `scripts/combat_routes.gd` с uid скрипта, `tests/combat_routes.gd` с uid скрипта, `tests/combat_routes.tscn` и этот отчёт.

Изменены `scripts/condition_evaluator.gd`, `scripts/combat_board.gd`, `tests/stage_seven_navigation.gd` и `docs/DESIGN_NOTES.md`.

`combat_routes.gd` рассчитывает геометрию и восстанавливает пути по истории. ConditionEvaluator проверяет доступность цели. EffectApplier применяет обычный манёвр и отмену. `combat_board.gd` показывает линию и анимирует модели.

## Как проверить руками

1. Запустить F5, вылететь и начать бой с пиратом.
2. Включить «Манёвр» и навести курсор на разные подсвеченные клетки. Должна появляться линия по соседним доступным клеткам.
3. Выбрать цель со смещением в сторону. При узкой части конуса линия сначала пройдёт вперёд, затем повернёт к цели. Нажать и проследить движение модели по этой линии.
4. Проверить клетки около корабля противника. Доступный обход должен огибать занятую клетку.
5. Нажать отмену последнего манёвра. Корабль пройдёт обратный маршрут, восстановятся позиция, курс и ОП.
6. Сохранить и загрузить бой после манёвра, затем повторить отмену. Завершить ход и проверить движение противника по клеткам.
