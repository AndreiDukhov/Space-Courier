# Этап 6: NPC-корабли и тестовые встречи

Отчёт фиксирует завершение этапа 6. В этапе 7 добавлены восьмой NPC, бой и `flight.defeated_npcs`; актуальные дополнения — в `docs/STAGE_7.md`.

## Что сделано

- Добавлены 7 тестовых кораблей: два в Солнечной системе, по одному в остальных пяти системах.
- NPC представлены оранжевыми 3D-конусами с подписями и движутся по замкнутым патрулям из JSON одновременно с игроком.
- Кнопка «Подлететь» берёт текущее положение NPC. Она задаёт точку на момент нажатия; дальнейшее слежение возможно зажатой ЛКМ.
- При сближении открывается тестовое событие. Кнопка «Связаться» доступна вблизи при выполнении условий события.
- В домашнюю систему добавлен жёлтый маркер `TODO событие`; подлёт к нему открывает событие с двумя вариантами.
- Открытая встреча останавливает игрока и NPC, блокирует фоновые команды полёта и показывает тексты из JSON. Пауза также останавливает оба вида кораблей.
- Условия события проверяет `ConditionEvaluator`, последствия выбора и реакции экипажа по тегам применяет `EffectApplier`. Повторное нажатие не дублирует последствия.
- Шанс события проверяется при входе в радиус встречи, а не каждый кадр. Повторный подход допускает новый бросок. В тестовых данных шанс равен 1.
- Реализована обработка `enter_system` из `event_pool` после межсистемного прыжка; текущие тестовые системы не содержат таких событий.
- NPC в незагруженных системах сохраняют последнее положение. Прыжки и возвращение из хаба не сбрасывают патрули.
- NPC продолжают движение, даже если у игрока кончилось топливо. Открытая встреча сохраняется вместе с позициями и текущими точками патрулей.
- Сохранение и загрузка доступны прямо в окне встречи. Загрузка не повторяет выбор и награду.
- Тексты и варианты — только `TODO scene text`; сюжет, настоящие диалоги, бой, арт и звук не добавлялись.

## Согласованные данные

Новый файл `data/galaxy/npcs.json`:

```json
{
  "id": "npc_earth_courier",
  "system": "sys_earth",
  "name": "TODO Courier 1",
  "pos": [620, 590],
  "waypoints": [[700, 590], [720, 500], [620, 500], [620, 590]],
  "speed": 35,
  "event": "event_courier_test"
}
```

`system` и `event` — ссылки по id. `waypoints` — последовательность точек карты; после последней NPC идёт к первой. `speed` задана в координатах карты за секунду.

События в `data/galaxy/events.json` используют существующий формат `trigger`, `chance`, `conditions`, `options`, `effects`, `tags`. Варианты выбираются по индексу; дополнительные поля выбора не вводились.

В существующий `GameState.state.flight` добавлены согласованные поля:

```json
{
  "npcs": {
    "npc_earth_courier": { "pos": [620.0, 590.0], "waypoint": 0 }
  },
  "encounter": ""
}
```

В настоящем сохранении `npcs` содержит все 7 кораблей. `waypoint` — индекс следующей цели, `encounter` — id текущего события или пустая строка. Остальные поля полёта `pos`, `target`, `paused` сохранены.

Загрузчик проверяет ссылки систем и событий, положительную скорость, границы и различие точек патруля, вероятность, структуру вариантов и их последствия. Триггер события должен соответствовать использующему его NPC или маркеру. Проверка сохранения отклоняет неизвестные NPC, неверные индексы и события без источника в текущей системе.

## Как проверить руками

1. F5 → `TODO office` → «Вылет в систему».
2. В домашней системе видны два оранжевых корабля с подписями `TODO Courier 1` и `TODO Transport 1`. Они должны двигаться даже при неподвижном корабле игрока.
3. Нажать пробел: игрок и NPC остановятся. Снять паузу — движение продолжится.
4. Подлететь к жёлтому кубу `TODO событие`, расположенному слева внизу от звезды. Это также можно сделать кнопкой «Подлететь» у события в прокручиваемой правой панели.
5. Появится окно «Встреча» с двумя вариантами `TODO scene text`. Все корабли стоят, фоновые команды недоступны.
6. Первый вариант маркера даёт 50 кредитов, второй расходует 0.5 топлива. В обоих случаях выставляется флаг завершения тестового события; оно больше не открывается в этой новой игре.
7. Приблизиться к `TODO Courier 1`: автоматически откроется встреча. Первый вариант даёт 25 кредитов, второй закрывает встречу без награды. Чтобы догнать корабль, можно двигаться за ним с зажатой ЛКМ или повторно нажимать «Подлететь».
8. `TODO Transport 1` использует другое событие: первый вариант даёт `private +1`, второй расходует 0.25 топлива и применяет тег `risk` к отношению экипажа.
9. Сохранить игру прямо во встрече, сделать выбор и загрузить сохранение. Окно должно восстановиться с прежними позициями, без преждевременной награды. Выбор после загрузки применяется один раз.
10. Перелететь в другую систему: там будет свой NPC. Возвращение и загрузка сохраняют прогресс патрулей.
11. Открыть `tests/stage_six_npcs.tscn`, нажать F6. Ожидается `Stage 6 NPC checks: 75 passed, 0 failed`.
