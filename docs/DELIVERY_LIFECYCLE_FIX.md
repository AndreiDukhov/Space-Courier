# Сдача доставки у планеты

Исправлено 2026-11-07.

## Что найдено

Журнал отображал только активные задания. После истечения срока заказ получал статус `failed` и исчезал из списка. Прыжки тратят игровые дни, поэтому просрочка может сработать при прибытии в систему.

Для `ord_private_01`, взятого в день 1, срок сдачи заканчивается в конце дня 3. Маршрут через Альфу занимает два дня, заказ остаётся активным при прибытии в Колонию-3. Маршрут через Бету и Дельту занимает три дня, поэтому при входе в Колонию-3 в день 4 заказ становится проваленным. Применяется штраф 120 кредитов и −1 репутации у частников.

Также общий метод завершения мог обойти проверку близости к планете. Прежний тестовый метод допускал завершение в офисе. Эти способы приведены к общей проверке доставки.

## Что сделано

- ConditionEvaluator проверяет систему, точную планету, расстояние от её поверхности, активный статус и срок для всех методов успешного завершения. Вход в систему сохраняет действующую доставку до передачи груза у цели.
- Прежний `complete_test_order` вызывает обычное действие доставки. Проверка внутри общего метода завершения также требует близости к цели.
- Журнал показывает все принятые задания. Активные размещаются первыми, закрытые — после них. На каждой карточке есть статус «Выполняется», «Выполнено» либо «Провалено».
- У закрытых доставок видны адрес, исходный срок и награда по договору. У активных добавлена подсказка о кнопке «Сдать заказ» над планетой.
- Применение статуса, награды и штрафов проходит через EffectApplier. Журнал читает существующее состояние `GameState.orders`.

## Как проверить руками

1. Начать новую игру. В офисе через компьютер взять `TODO private order 01` и `TODO state order 01`.
2. Вылететь через компьютер мастерской. Пройти Солнечная → Альфа → Колония-3. Сразу после входа в Колонию открыть «Задание». Оба заказа должны иметь статус «Выполняется», деньги и груз сохраняются до сдачи.
3. Подлететь к другой планете Колонии. Подходящая кнопка сдачи появится у планеты назначения `TODO Планета-3`.
4. У нужной планеты нажать «Сдать заказ» для частной доставки. Получить 600 кредитов. В журнале частный заказ станет выполненным, государственный останется активным.
5. Для проверки просрочки начать новую игру, взять те же заказы и пройти Солнечная → Бета → Дельта → Колония-3. Прибытие произойдёт в день 4. Частный заказ будет виден в журнале как проваленный, государственный останется активным до конца дня 4.
6. Сохранить и загрузить игру в обоих сценариях. Проверить статусы и однократное применение награды либо штрафа.
