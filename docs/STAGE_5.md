# Этап 5: карта и доработка карточек заказов

Это отчёт о версии этапа 5. В первом шаге этапа 6 прямой прыжок с глобальной карты заменён полётом к червоточине; исправлено раскрытие неизвестных направлений. Актуальная инструкция — в `docs/STAGE_6.md`.

## Что сделано

- Карточка заказа показывает оплату из денежных эффектов `reward`, название системы и название конкретной планеты назначения до приёма заказа.
- Вместо JSON при наведении выводится `description`: пока это повторение слова «текст». Подсказки кнопок тоже заменены обычным текстом.
- Тексты новых элементов интерфейса хранятся в `data/ui/*.json`.
- В кабинете здания добавлена кнопка «Карта». Хаб остаётся зданием: после прыжка игрок находится на мостике, а возвращение в интерфейс здания доступно после прилёта в домашнюю систему.
- В JSON заданы 6 тестовых систем и 10 направленных маршрутов. Обратный путь — отдельная запись со своим расходом и длительностью.
- Системы имеют состояния `hidden`, `seen`, `visited`. Туман скрывает неизвестные системы; обнаруженная система показывает значок и название. При посещении становятся видны её выходы.
- Принятый заказ обнаруживает систему назначения, но не раскрывает ведущие к ней маршруты.
- До изучения виден диапазон расхода; после прохода раскрывается точное значение только для пройденного направления.
- Планирование использует Дейкстру: среднее диапазона для неизвестного расхода, точное значение для изученного. Интерфейс предупреждает о неизвестном возвращении или недостаточном запасе на обратный путь.
- Расход равен `ceil(base_fuel * (1 + 0.05 * active_cargo_mass))`. Форсаж дополнительно умножает расход на 1.5 перед округлением. Баланс вынесен в константы.
- Для неизвестного расхода требуется запас по верхней границе диапазона. Состояние кнопки прыжка не выдаёт скрытое точное значение.
- Прыжок продвигает игровые дни; расписания и просрочка заказов используют существующие механизмы.
- Доступны заправка по цене системы, однократная продажа изученного частного маршрута по `map_value`, сохранение и загрузка.
- Тестовый буксир возвращает застрявший корабль в хаб с полным баком, тратит день и списывает 400 кредитов с возможностью долга. Доступен при нулевом топливе либо отсутствии доступного прыжка и возможности заправиться. Стоимость и длительность — константы `EffectApplier`.
- Все разрешения проверяет `ConditionEvaluator`, изменения мира применяет `EffectApplier`. Добавлен эффект `unlock_route` из исходной схемы.
- Загрузчик проверяет диапазоны расхода, ссылки, принадлежность планеты системе, уникальность id планет и существование направленного пути домой из каждой системы.

## Согласованные дополнения данных

В заказ добавлены поля:

```json
{
  "description": "текст текст текст",
  "to_planet": "colony_3_1"
}
```

`to` остаётся id системы. `to_planet` — id объекта типа `planet` в её `objects`. Для отображения названия планете добавлено поле `name`:

```json
{ "type": "planet", "id": "colony_3_1", "name": "TODO Планета-3", "pos": [500, 320] }
```

В `GameState` и сохранение добавлены согласованные поля:

```json
{
  "current_system": "sys_earth",
  "systems": {
    "sys_earth": "visited",
    "sys_alpha": "seen",
    "sys_far": "hidden"
  },
  "public_routes": ["r_earth_alpha"]
}
```

В реальном сохранении `systems` содержит все системы. Уже существующий `known_routes` хранит id изученных маршрутов. `public_routes` содержит общедоступные маршруты, включая начальные значения из JSON и проданные игроком. Исходные JSON при этом не изменяются.

## Как проверить руками

1. Нажать F5, перейти в `TODO office`, открыть `orders`.
2. Проверить оплату в карточках: частный заказ 01 — 600 кредитов, государственный 01 — 900, криминальный 01 — 1600. Система и планета назначения находятся под оплатой.
3. Навести курсор на карточку: подсказка состоит из слова «текст», JSON отсутствует. Кнопки `+`, `✓`, `×` имеют обычные текстовые подсказки.
4. Для проверки расхода без груза не принимать заказ. Закрыть терминал и нажать «Карта» в кабинете.
5. Выбрать `TODO Альфа`. Видны расход 3–6 и предупреждение «Обратный путь неизвестен».
6. Нажать «Прыжок по первому участку». День станет 2, топливо — 26/30. У пройденного участка появится точный расход 4. Расход обратного участка останется диапазоном 4–7. Кнопка возвращения в хаб недоступна, потому что игрок в другой системе.
7. Выбрать `TODO Солнечная`, снова прыгнуть. День станет 3, топливо — 21/30. Теперь можно продать карту обратного участка за 60 кредитов и вернуться в кабинет.
8. На карте проверить заправку и кнопки сохранения/загрузки. Сохраняются текущая система, туман, изученные и опубликованные маршруты, топливо, деньги и время.
9. Для автоматических проверок открыть `tests/stage_five.tscn` и нажать F6. Ожидается `Stage 5 checks: 110 passed, 0 failed`.

## Ограничения

- Переходы выполняются тестовой кнопкой на карте. Целевое поведение уточнено пользователем: отдельная карта системы, полёт в реальном времени и переход через червоточину на её краю. Неизвестное назначение скрыто до получения сведений или первого прохода. Подробности и отличия текущего прототипа записаны в `docs/DESIGN_NOTES.md`.
- `✓` в терминале по-прежнему завершает тестовый заказ. Проверка фактической доставки на планету пока не реализована.
- Буксир — тестовая страховка без событийного диалога. Система событий и влияние опубликованных маршрутов на патрули и мафию ещё не реализованы.
- Используется базовая цена заправки. Формула скидки по репутации в исходной схеме не задана и не добавлялась.
- Покупка предметов-карт появится вместе с соответствующими данными и инвентарём; сейчас доступны исследование и продажа маршрутов.
- Сейвы без новых согласованных полей отклоняются; миграции старых сейвов нет.
- Названия, описания и баланс тестовые. Настоящий сюжет, диалоги, арт и звук не добавлялись.

Этап 6 не начат. Коммиты не выполнялись.
