# Выбор корабля, компьютеры и время суток

Обновлено 2026-11-06 по четырём поправкам пользователя. Формат данных освещения согласован в чате. Поведение клика по кораблю уточнено 2026-11-07.

## Что сделано

- ЛКМ по близкому кораблю включает паузу и показывает действия над ним. Дистанция взаимодействия составляет 48 единиц карты. Клик по дальнему кораблю задаёт курс. Пролёт рядом с кораблём продолжает локальную симуляцию. Продолжение полёта скрывает действия корабля.
- Утро, день, вечер и ночь имеют отдельные параметры освещения. Вечером помещение затемняется, выделенные лампы и экраны остаются яркими. Ночью затемняются помещение и источники света. Миниатюры комнат используют дневную яркость для читаемости навигации.
- Заказы открываются кликом по экрану компьютера на столе в офисе. При наведении появляется «Открыть заказы».
- Вылет и карта галактики открываются через компьютер в мастерской `hub_tech`. Клик по монитору на рабочем столе слева открывает меню с кнопками карты и вылета. Подсказка показывает «Открыть управление вылетами». Проверки доступа и действие запуска перенесены в мастерскую.

Освещение рассчитывается шейдером по яркости пикселей и заданным областям ламп и экранов. Границы маски света сглажены. Параметры и области находятся в JSON и служат стартовой настройкой.

Пауза хранится в `GameState.flight.paused`. Доступность выбора, общения, торговли и компьютеров проверяет ConditionEvaluator. Пауза и запуск полёта применяются через EffectApplier.

## Согласованные данные

Запись `hub_lighting` находится в `data/ui/hub.json`.

```json
{
  "id": "hub_lighting",
  "slots": {
    "morning": {"ambient": 0.86, "light_gain": 0.12},
    "day": {"ambient": 1.0, "light_gain": 0.0},
    "evening": {"ambient": 0.36, "light_gain": 1.4},
    "night": {"ambient": 0.055, "light_gain": 0.0}
  },
  "locations": {
    "hub_office": {
      "light_rects": [[0.39, 0.375, 0.105, 0.095]]
    }
  }
}
```

`ambient` задаёт множитель основного изображения. `light_gain` усиливает яркие пиксели в областях источников света. Прямоугольники `light_rects` содержат нормализованные x, y, ширину и высоту относительно полной фоновой картинки. В рабочих данных заданы области главного зала, офиса, мастерской и спальни.

Для компьютеров используется формат областей взаимодействия с `location` и `zones.computer.drop_rect`. Записи `hub_office_hotspot` и `hub_tech_hotspot` ссылаются на соответствующие комнаты. Области учитывают масштабирование и обрезку фоновой картинки, как область готовки.

DataLoader проверяет все четыре слота, конечные неотрицательные параметры яркости, ссылки на комнаты и границы прямоугольников. Действия `flight` и `galaxy_map` находятся в записи мастерской, действие `orders` — в записи офиса.

## Ручная проверка

1. Запустить F5. В главном зале несколько раз нажать ожидание. Днём фон светлый, вечером помещение тёмное с яркими панелями и лампами, ночью фон почти тёмный. Надписи интерфейса и миниатюры комнат читаемы.
2. Перейти в офис, навести мышь на экран компьютера на центральном столе. Подсказка должна следовать за курсором. Нажать и проверить список заказов.
3. Закрыть заказы и перейти в мастерскую. Нажать на монитор рабочего стола слева, открыть карту, вернуться и через этот же компьютер начать вылет.
4. В полёте пройти рядом с гражданским кораблём. Полёт должен продолжаться. Нажать непосредственно на модель корабля. Должны включиться пауза и действия над выбранной моделью.
5. Нажать на дальний корабль и проверить продолжение полёта к выбранной точке. После подлёта снова нажать на модель и открыть диалог либо торговлю транспорта. Продолжить полёт пробелом или кнопкой паузы.
6. Сохранить игру во время паузы, загрузить и повторно выбрать корабль. Проверить продолжение полёта и вход в бой через диалог с пиратом.
7. Повторить клики по обоим компьютерам и кораблю при размере окна 900×600.
